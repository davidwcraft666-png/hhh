# AI 学习实验室

本项目包含一个面向中文学习者的 **AI 教学网站**，以及一个可选的命令行脚本 `fetch_web_info.py`，用于抓取或解析网页信息。你可以根据需求选择使用其中任意部分。

## 在线教学网站

- `index.html`：网站主页，展示课程亮点、12 周课程规划、导师团队、常见问题与体验课报名表单。
- `styles.css`：为网站提供渐变背景、时间线、FAQ 手风琴等现代风格的视觉设计，并适配移动端。
- `app.js`：负责渲染课程时间线与 FAQ 数据、筛选学习阶段、验证表单并给出提交反馈。

### 预览方式

1. 运行附带的快捷脚本自动启动本地服务器：
   ```bash
   python serve_site.py
   ```
   终端会显示可访问的网址（通常为 `http://localhost:8000/index.html`），并尝试自动在默认浏览器中打开。
2. 如果你更倾向手动操作，也可以运行：
   ```bash
   python -m http.server 8000
   ```
   然后访问 `http://localhost:8000/index.html`。

## 命令行网页信息抓取（可选）

`fetch_web_info.py` 依旧可用于提取网页或本地 HTML 文件中的标题、描述和主要段落，适用于需要快速了解网页概要的场景。

### 使用方法

```bash
# 直接抓取在线网页
python fetch_web_info.py https://example.com

# 或解析本地 HTML 文件
python fetch_web_info.py saved_page.html
```

如果在命令行中不提供网址或文件路径，程序会提示输入。

该脚本仅依赖 Python 标准库，无需额外安装第三方包。

当网络受限（例如出现 `403 Forbidden`）时，可以先在其他设备下载网页 HTML，再将文件上传至当前环境，最后改为解析本地文件。

如果抓取在线网页失败，脚本还会自动提示是否改为读取本地 HTML 文件，按照提示输入已下载的文件路径即可继续完成信息提取。
